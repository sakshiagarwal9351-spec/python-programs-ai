# Python Programs Using AI Assistance

## Project Overview

This repository contains three basic Python programs converted from C programs with the assistance of Artificial Intelligence.

The project demonstrates fundamental programming concepts such as loops, conditional statements, mathematical operations, and dictionaries.

## Objectives

- Convert C programs into Python using AI assistance.
- Understand the differences between C and Python syntax.
- Practice basic Python programming concepts.
- Learn how to document and manage projects using GitHub.

## Technologies Used

- Python 3
- GitHub
- ChatGPT (AI assistance)

## Programs Included

### 1. Factorial Calculator
Calculates the factorial of a given non-negative integer using a for loop.

**Example Output:**
```text
Enter a number: 5
Factorial of 5 is 120
```

### 2. Fibonacci Series Generator
Generates the Fibonacci sequence for the number of terms entered by the user.

**Example Output:**
```text
Enter the number of terms: 7
Fibonacci Series: 0 1 1 2 3 5 8
```

### 3. Student Details Using Dictionary
Stores and displays student information such as name, roll number, and marks using a Python dictionary.

**Example Output:**
```text
Enter student name: Rahul
Enter roll number: 101
Enter marks: 87.5

Student Details
Name: Rahul
Roll Number: 101
Marks: 87.50
```

## How to Run the Programs

1. Install Python 3 on your computer, or use an online Python compiler.
2. Download or clone this repository.
3. Open the required Python file.
4. Execute the program.
5. Enter the requested input.
